# Employee-Tracker
A personal project where I try to learn the basics of html, css and javascript in order to create a webpage which solved employee clocking in, clocking out, tardiness, database handling, and generates work statistics and payslips for hours worked.
## Methods
I will not use AI to generate code or advice for this project. I will rely on webpage documentation such as w3schools and GeeksforGeeks for information on file structure and procedure. My goal is to make a very well structured code base, with a good Git history.
